hatex examples

  • basic.html — the smallest page: LaTeX in a script tag, one render call.
  • editor.html — live editor: re-render on type, problems list, double-click to source, DOI → \bibitem, dark mode.
  • tikz.html — TikZ, the nn styles and pgfplots; pre-rendered SVGs vs. live compile.
  • document/ — a full article fetched from example.tex: every feature, with images and TikZ.
  • node/prerender.mjs — render a .tex file to static HTML in Node (npm run prerender).
